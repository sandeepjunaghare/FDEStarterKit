| Rubric row                | Choice                                                                                                                    | One-sentence defense                                                                                                              |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Multi-agent orchestration | Planner/router → Retriever → Answer-with-citations → Critic/guardrail (4 agents)                                          | Each agent has one job; the critic is the agent I would review hardest if a junior built it                                       |
| Framework                 | Claude Agent SDK, FastAPI with SSE                                                                                        | Outputs are checked against Pydantic schemas, so guardrails live in code, not prompts                                             |
| Vector DB                 | pgVector on Supabase (cloud)                                                                                              | One managed Postgres holds vectors and user memory, identical for local and Render                                                |
| Embedding model           | Voyage AI voyage-4, 1024 dims, $0.06/1M tokens (200M free), input_type query/document                                     | Anthropic's recommended embeddings provider; hosted beats local for a prototype; 1024 fits pgvector HNSW; swap is one config line |
| Memory                    | Session memory (conversation) + persistent memory (user profile in Postgres)                                              | Two layers, scoped per user, both shown in the UI                                                                                 |
| Guardrails                | Pydantic schemas, input scope classifier, PII redaction, citation-required answers, out-of-scope refusal, one domain rule | Cost of a wrong answer decides strictness                                                                                         |
| LLM Eval                  | 10–15 golden Q&A pairs, retrieval hit rate, faithfulness via LLM-as-judge (Langfuse)                                      | Show a failing eval, fix it, rerun on camera                                                                                      |
| Deployment                | Docker → Render, rehearsed to a 5-minute step                                                                             | Cloud is extra points only if it does not eat the front end                                                                       |
| Front end                 | Streamlit by default; React only if Ex1 finishes with 30+ minutes spare                                                   | The rubric says the front end matters, not that it must be React                                                                  |
| GitHub                    | Public repo, README with architecture, run, eval and deploy sections, committed every 20 minutes                          | Commit log is evidence of parallel work                                                                                           |
